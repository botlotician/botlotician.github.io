# 2026 Promise Tracker: Hollister & California

Live site: https://botlotician.github.io/

This is a static site with no build step and no backend. `index.html`, `styles.css` and `app.js` load
`data/promises.json`. The ZIP lookup loads `data/zips_ca.json` only when a visitor enters a ZIP.
The last ZIP entered is kept in the visitor's browser (localStorage) and is never sent anywhere.

## Data files (`data/`)
| File | What it is | How it changes |
|---|---|---|
| `promises_2026.csv` | 2026 candidate promises: race, level, candidate, party, promise, topic, source_url, source_date | Edit by hand or copy from research |
| `president_2024.csv` | President's 2024 promises with status | Edit by hand |
| `races.csv` | Who votes in each race. Drives the ZIP lookup (see below). Every race in `promises_2026.csv` needs a row. | Add a row per new race |
| `notes.json` | Last-updated date, race notes, races with no promises, coverage settings | Edit by hand |
| `promises.json` | Generated by `build_data.py`. Do not edit. | `python3 build_data.py` |
| `zips_ca.json` | California ZIP to county, places and districts. Generated by `tools/build_zip_data.py`. | Rarely: only if district lines change |

### `races.csv` area types
| area_type | area_id | Shown for a ZIP when... |
|---|---|---|
| `state` | `CA` | the ZIP is in California |
| `cd` / `ad` / `sd` / `boe` | district number (e.g. `18`) | the ZIP overlaps that U.S. House / Assembly / State Senate / Board of Equalization district |
| `county` | county name (e.g. `San Benito`) | the ZIP overlaps that county |
| `city` | city name (e.g. `Hollister`), with `county` filled in | the ZIP overlaps that city's limits (Census incorporated place) |

`who_votes` is shown under the race (e.g. "Voters in Supervisor District 5 only").
Districts that overlap a ZIP but have no races in the tracker are shown as **Not tracked yet**.
`notes.json` → `coverage.on_ballot_2026` controls the "Not on the 2026 ballot" label. For example, State Senate is `even`.

**To add a new area** (e.g. Gilroy, or CA-19), add the promises to `promises_2026.csv`, add one row per race to
`races.csv`, add the county to `coverage.tracked_counties` in `notes.json` if it's new, then rebuild. No code changes are needed.

## Update and republish
```
cd /workspace/promise-site
python3 build_data.py --from /workspace/promises   # or edit data/*.csv in place and run: python3 build_data.py
python3 -m http.server 8000                        # preview at http://localhost:8000 (try #zip=95023)
git add -A && git commit -m "Data update YYYY-MM-DD" && git push   # GitHub Pages redeploys in about a minute
```
`build_data.py` stops with line-numbered errors on bad data, for example a missing source URL, an unknown status,
or a race without a `races.csv` row.

## ZIP data sources (`tools/build_zip_data.py`, built Oct. 21, 2026)
All sources are official public files. The script downloads them into a cache, then aggregates 2020 Census blocks to ZIP Code
Tabulation Areas (ZCTAs), weighted by 2020 population. A ZIP lists **every** district or county that contains any populated block of
that ZIP, plus each one's share of residents. Unpopulated ZIPs list every overlap.
- **ZIP areas:** U.S. Census Bureau 2020 ZCTA-to-block relationship file (`rel2020/zcta520/tab20_zcta520_tabblock20_natl.txt`).
- **Population, county and place names:** 2020 Census P.L. 94-171 redistricting data for California, and the 2020 block assignment file for incorporated places and CDPs.
- **U.S. House (2026 ballot):** the Census Bureau 120th Congress block equivalency file (`rdo/mapping-files/2027/120-congressional-district-befs/cd120.zip`, Oct. 2026).
  This is California's Prop. 50 / AB 604 map. The CA Secretary of State says 2026 primary and general ballots use the new districts.
  The script checks it block by block against the Legislature's AB 604 equivalency file (statewidedatabase.org/pub/data/d25/AB604.zip) and found 0 mismatches.
  The 2021 (119th Congress) map is intentionally **not** used.
- **State Assembly / Senate:** Census 2026 state legislative block equivalency files (`rdo/mapping-files/2027/2026-state-legislative-bef/`).
  These are the 2021 Citizens Redistricting Commission maps, which Prop. 50 did not change. They were cross-checked against the Census ZCTA-to-SLD 2024 relationship files.
- **Board of Equalization:** CA Citizens Redistricting Commission final 2021 BOE equivalency file (wedrawthelines.ca.gov/final-maps/).
- **County elections office links:** CA Secretary of State county elections offices page.
- **PO Box ZIPs** have no ZCTA. `notes.json` → `coverage.po_box_zips` maps 95024 (Hollister PO Boxes) to 95023, the ZIP it sits inside, and the page says so.
  Other non-ZCTA California ZIPs (prefixes 900–961) show statewide races only.

Caveat: ZCTAs approximate USPS ZIP codes, and a ZIP can be split across districts. The site always tells visitors to check
their official sample ballot.

To rebuild the ZIP file (about 1.3 GB of downloads, roughly 1 minute of processing): `python3 tools/build_zip_data.py --cache /tmp/zipcache`
