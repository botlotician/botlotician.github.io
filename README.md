# Botlotician Promise Tracker

The President's 2024 promises, and what candidates on your 2026 ballot are promising. Nationwide, by ZIP code.

Live site: https://botlotician.github.io/

This is a static site with no build step and no backend. `index.html`, `styles.css` and `app.js` load `data/promises.json`.
When a visitor enters a ZIP, the page loads a tiny index (`data/zips/index.json`, ~14 KB), the one state file it needs
(`data/zips/ST.json`, 3–270 KB) and the national race list (`data/races_2026.json`). Nothing else is loaded up front.
The last ZIP entered is kept in the visitor's browser (localStorage) and is never sent anywhere.

## Page layout
- **Main page:** the *President's 2024 promises* tab and the ZIP box. A *Your ZIP* tab appears after a lookup.
- **ZIP results** (any of the 50 states or D.C.) show:
  - the location (city/community, county, state);
  - the 2026 U.S. House district, with a split warning when the ZIP crosses district, county, city or state lines. At-large states and D.C.'s non-voting delegate are labeled;
  - the state's 2026 U.S. Senate race(s), regular and special;
  - the governor's race if there is one (D.C.: mayor);
  - in California, the other statewide offices, Assembly, State Senate, BOE and the tracked local races.
  
  Every race is labeled **Tracked** (sourced promises below) or **Not tracked yet**. Untracked races show the general-election
  candidates (from Ballotpedia) and a Ballotpedia race link, or the Ballotpedia sample ballot lookup if there is no race page.
  The official links are the state election office (USA.gov list), California voter status and county offices, Vote.org, VOTE411
  and the Ballotpedia sample ballot. *Request my city* opens a prefilled public GitHub issue.
- **Old links:** `#state`, `#local` and old `#race-...` anchors open the visitor's saved ZIP results if they cover that race.
  Otherwise they go to the ZIP box with a hint.
- Territory and military ZIPs get a message. Unknown ZIPs in a known state prefix show that state's Senate and governor races.
- Search and the topic filter work on the President tab and on ZIP results. The status filter appears on the President tab only.

## Data files (`data/`)
| File | What it is | How it changes |
|---|---|---|
| `promises_2026.csv` | California candidate promises: race, level, candidate, party, promise, topic, source_url, source_date | Edit or copy from research |
| `national_2026.csv` | *Optional.* Promises for any state's federal/statewide races (format below) | Copy in with `--from` |
| `president_2024.csv` | President's 2024 promises with status | Edit by hand |
| `races.csv` | Who votes in each California race (drives the ZIP lookup); optional `race_id` links a race to the national list | Add a row per new CA race |
| `races_2026.csv` | Every 2026 U.S. Senate, governor, D.C. mayor and U.S. House general election: race_id, state, office, district, on_ballot, candidates, Ballotpedia URL, note | `python3 tools/fetch_races_2026.py` |
| `state_election_offices.csv` | One official election office link per state + D.C. (USA.gov) | Rarely |
| `notes.json` | Last-updated date, race notes, races with no promises, coverage settings | Edit by hand |
| `promises.json`, `races_2026.json` | Generated by `build_data.py`. Do not edit. | `python3 build_data.py` |
| `zips/ST.json`, `zips/index.json` | ZIP to state(s), county, places and 2026 House district (+ CA legislative districts). Generated by `tools/build_zip_national.py`. | Only if district lines change |

### `national_2026.csv` format
`race,level,state,race_id,candidate,party,promise,topic,source_url,source_date`
- `level`: `federal` (U.S. Senate / House) or `statewide` (governor, D.C. mayor).
- `state`: 2-letter code. `race_id` must be a row in `races_2026.csv` for that state, marked on the ballot:
  `US-SEN-TX`, `US-SEN-OH-SPECIAL`, `US-SEN-FL-SPECIAL`, `GOV-TX`, `MAYOR-DC`, `US-HOUSE-TX-23`, `US-HOUSE-AK-AL` (at-large), `US-HOUSE-DC-AL` (delegate).
- `source_url` is required; `source_date` is `YYYY-MM-DD` (or `YYYY-MM`).
- `build_data.py` stops with line-numbered errors for a bad level, state, race_id, URL or date, or a race that isn't on the 2026 ballot.
  Every race in the file then shows as **Tracked** in the ZIP results for that state or district, with its promise cards.

### `races.csv` area types (California)
| area_type | area_id | Shown for a ZIP when... |
|---|---|---|
| `state` | `CA` | the ZIP is (partly) in California |
| `cd` / `ad` / `sd` / `boe` | district number (e.g. `18`) | the ZIP overlaps that U.S. House / Assembly / State Senate / Board of Equalization district |
| `county` | county name without "County" (e.g. `San Benito`) | the ZIP overlaps that county |
| `city` | city name (e.g. `Hollister`), with `county` filled in | the ZIP overlaps that city's limits (Census incorporated place) |

`notes.json` → `coverage.on_ballot_2026` controls the "Not on the 2026 ballot" label for CA legislative districts (State Senate is `even`).

## Update and republish
```
cd /workspace/promise-site
python3 build_data.py --from /workspace/promises   # copies promises_2026.csv, president_2024.csv and national_2026.csv (if present)
python3 -m http.server 8000                        # preview at http://localhost:8000 (try #zip=78701)
git add -A && git commit -m "Data update YYYY-MM-DD" && git push   # GitHub Pages redeploys in about a minute
```

### When `/workspace/promises/national_2026.csv` lands
```
cd /workspace/promise-site
python3 tools/fetch_races_2026.py                  # optional: refresh candidates / race list from Ballotpedia (~4 min)
python3 build_data.py --from /workspace/promises   # copies + validates national_2026.csv; fix any line-numbered errors it prints
python3 -m http.server 8000                        # check a ZIP in each new state, e.g. #zip=78701 for US-SEN-TX / GOV-TX / US-HOUSE-TX-10
git add data/ && git commit -m "Add national 2026 promises" && git push
gh api repos/botlotician/botlotician.github.io/pages/builds/latest --jq .status   # "built" = live
```
No code changes are needed: races in the file switch from "Not tracked yet" to "Tracked" automatically.

## ZIP data sources (built Oct. 21, 2026)
`tools/prep_national.sh` downloads the official Census files and splits them by state. `tools/build_zip_national.py` then aggregates
2020 Census blocks to ZIP Code Tabulation Areas (ZCTAs), weighted by 2020 population. A ZIP lists **every** state, county and district
that contains any populated block of it, with each one's share of residents. Unpopulated ZIPs list every overlap.
- **ZIP areas:** Census 2020 ZCTA-to-block relationship file (`rel2020/zcta520/tab20_zcta520_tabblock20_natl.txt`).
- **Population, county and place names:** 2020 Census P.L. 94-171 redistricting data geo headers for the 50 states and D.C.
- **U.S. House (Nov. 3, 2026):** Census 120th Congress block equivalency file `NationalCD120.txt`
  (`rdo/mapping-files/2027/120-congressional-district-befs/cd120.zip`), the districts for the 2026 elections.
  The Census Bureau says nine states drew new boundaries for 2026: Alabama, California, Florida, Louisiana, North Carolina, Ohio,
  Tennessee, Texas and Utah. A block-by-block comparison against the 119th Congress file found changes in exactly those nine states
  (AL 12.7%, CA 25.7%, FL 25.5%, LA 28.5%, NC 8.0%, OH 17.3%, TN 35.3%, TX 28.7%, UT 67.2% of blocks reassigned) and no others.
  Missouri's 2025 map was blocked before the election, and the Census file keeps its 2022 map.
  California is also checked against the AB 604 (Prop. 50) equivalency file: 0 mismatches.
- **California Assembly / Senate / BOE:** Census 2026 state legislative BEFs and the CRC 2021 BOE equivalency file (`tools/build_zip_data.py` helpers).
- **Races and candidates:** Ballotpedia 2026 Senate, gubernatorial, D.C. mayoral and state U.S. House election pages (`tools/fetch_races_2026.py`).
  Only race pages Ballotpedia itself links to are used. Write-ins are excluded.
- **State election offices:** USA.gov, https://www.usa.gov/state-election-office.
- **PO Box ZIPs** have no ZCTA. `notes.json` → `coverage.po_box_zips` maps 95024 (Hollister PO Boxes) to 95023.

To rebuild the ZIP files (about 2 GB of downloads): `tools/prep_national.sh && python3 tools/build_zip_national.py`

Caveat: ZCTAs approximate USPS ZIP codes, and a ZIP can be split across districts. The site always tells visitors to check their official sample ballot.
